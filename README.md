# 🎵 Muzes Lavalink List

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

A community-maintained list of Lavalink nodes for music bots. Submit your own public Lavalink servers to help others!

## 🌟 Features
- Curated list of stable Lavalink nodes
- Easy-to-use format
- Community-powered (submit your nodes)
- Regularly updated

## 🚀 Quick Start

1. Install pnpm:
```bash
npm install -g pnpm
```

2. Install dependencies:
```bash
pnpm install
```

3. Run the project:
```bash
pnpm dev
```

## 📥 Submitting Nodes
Want to add your public Lavalink node? 

1. Fork this repository
2. Add your node to the list (see format below)
3. Create a Pull Request

Node format:
```json
{
  "name": "Your Node Name",
  "host": "your.lavalink.host",
  "port": 2333,
  "password": "yourpassword",
  "secure": false,
  "region": "NA/EU/ASIA/etc"
}
```
